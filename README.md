## 🌿 What I Build

I design and code at the intersection of **material aesthetics and generative systems** — building design languages, interactive art tools, and AI-powered experiences. My work pulls from the physical world: wood grain, crystal facets, botanical color, textile texture. Each project is a design system as much as it is a product.

## 🎨 Design System Family

My design systems share a common philosophy: interfaces should feel **tactile, material, and joyful** — like objects you want to pick up and touch.

```
📐 Design Standards 2026–2027  ←  shared foundation
   ├── 🌸 Chromaflora         (botanical color, flora energy)
   ├── 💎 Jewelmorphism       (crystal depth, soft shadow physics)
   └── 🪵 Woodmorphism        (earthy grain, natural warmth)
```
